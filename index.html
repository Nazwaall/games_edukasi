ℹ️ ABOUT THE GAME

Uji Pengetahuan Umum: Rank Bronze to Mythic adalah web game trivia edukasi interaktif yang mengombinasikan pengetahuan akademis dengan sistem kompetitif game modern.


✔ No Login & Instant Play: Progress disimpan otomatis di browser (localStorage).
✔ 60+ Soal Kuis Utama + Soal Preview Khusus Materi dari Sains, Sejarah, Logika, Bahasa, Teknologi, Geografi, dan Budaya.
✔ Timer Per Soal: Menantang kecepatan dan ketepatan berpikir.
✔ Mobile-First Design: Responsif dan nyaman dimainkan di HP, Tablet, maupun PC.
